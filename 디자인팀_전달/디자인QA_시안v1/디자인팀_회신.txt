- 예상 시간 문구의 취소선 오류 수정

■ 전달사항과 다르게 한 점
1. 집계의 "전체"(counts.total)는 처리 건수가 아니라 입력 건수였습니다.
   처리 건수는 counts.processed로 따로 저장하고, 화면은 "처리 N건 / 입력 M건"으로 표시합니다.
2. 안전 정지의 진행 막대를 주황으로 바꾸지 못했습니다.
   Streamlit 진행 막대는 주 색 한 가지만 써서, 배지만 주황이고 막대는 주 색입니다.
3. 업로드 상자 안의 "Upload", "25MB per file" 문구는 Streamlit 고정 영어 문구라 바꿀 수 없습니다.
   상자 위 라벨에 "파일 선택 · 또는 여기에 끌어 놓기 · .xlsx 한 개"를 넣었습니다.
4. 모바일에서도 실행 중·안전 정지 작업의 상세가 펼쳐진 채로 나옵니다.
   Streamlit에서 화면 폭을 알 수 없어 데스크톱과 같은 규칙을 씁니다.
5. 사이드바의 "지금 서버" 숫자는 페이지를 다시 그릴 때 바뀝니다. 작업 목록은 5초마다 바뀝니다.
6. 안전 정지 안내의 "멈춘 이유"는 서버가 기록한 원인으로 채웁니다.
   예: "사이트 연결 오류가 5번 이어져", "다시 로그인이 계속 실패해".
